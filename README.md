*Conclusion
This project is a SQL-based Pizza Sales Analysis built on a relational database (pizzahunt) with four core tables — orders, order_details, pizzas, and pizza_types.

*Key Findings
Total Revenue & Volume — Aggregated overall sales and quantity sold across all orders.
Best Sales Day — Identified the single highest-revenue date using a date-grouped query.
Popular Size — Determined which pizza size (S/M/L/XL) drives the most orders.
Top 3 Best-Sellers — Ranked individual pizza IDs by quantity sold.
Category Performance — Compared total quantity sold across pizza categories (Classic, Veggie, Supreme, etc.).
Most Profitable Pizza — Found the pizza name generating the highest total revenue.
Average Daily Orders — Calculated average pizzas ordered per day via a reusable sales_dashboard view.
