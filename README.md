Overview
Pizza Hunt is a SQL-based data analytics project that analyzes pizza sales data to generate meaningful business insights using MySQL queries.
This project demonstrates how SQL can be used for:
Sales analysis
KPI reporting
Business intelligence
Revenue tracking
Product performance evaluation
This project simulates a real-world pizza sales business environment where raw transactional data is transformed into actionable insights using SQL. By working with multiple relational tables, the analysis helps identify sales trends, customer ordering behavior, and high-performing pizza categories.
The project is designed for students, aspiring data analysts, and SQL beginners who want hands-on experience with business-focused database analysis. It demonstrates how SQL queries can support data-driven decision-making and improve operational understanding.
The project includes:
Database creation and table management
KPI analysis
Sales and quantity analysis
Dashboard-related SQL queries
