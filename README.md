Pizza Hunt SQL Analytics Project

Overview
Pizza Hunt is a SQL-based data analytics project designed to analyze pizza sales data and generate business insights using SQL queries.

The project includes:
Database creation and table management

KPI analysis
Sales and quantity analysis
Dashboard-related SQL queries
Business performance insights
Tables

The project works with the following tables:
orders
order_details
pizzas
pizza_types
sales_dashboard
Features

KPI Analysis
The project calculates:
Gross Sales
Total Quantity Sold
Total Pizza Types
Average Daily Pizza Sold

Dashboard Queries
Includes SQL queries for:
Total sales and quantity sold
Highest sales day
Revenue analysis

Product performance analysis

Order statistics
