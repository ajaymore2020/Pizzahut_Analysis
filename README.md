## Key Points from the Pizza Hunt SQL Analysis

* Created and used a database named **`pizzahunt`**.
* Worked with four main tables:

  * `orders`
  * `order_details`
  * `pizzas`
  * `pizza_types`

### KPIs Calculated

* **Gross Sales** using total revenue.
* **Total Quantity Sold** from order details.
* **Total Pizza Types** available.
* **Average Daily Pizza Sold** from the sales dashboard.

### Business Analysis Performed

* Calculated:

  * Total sales
  * Total quantity sold
* Identified:

  * The **day with the highest sales**
  * The **most popular pizza size**
  * The **top 3 best-selling pizzas**
  * Quantity sold by **pizza category**
  * The **most profitable pizza type/category**

### SQL Concepts Used

* `JOIN`
* `GROUP BY`
* `ORDER BY`
* Aggregate functions:

  * `SUM()`
  * `COUNT()`
  * `AVG()`
  * `ROUND()`
* `LIMIT` for top-performing results.

---

## Conclusion

The SQL project successfully analyzes pizza sales performance using multiple relational tables. It helps identify important business insights such as top-selling pizzas, profitable categories, customer preferences for pizza sizes, and peak sales days. The project demonstrates strong use of SQL queries, joins, and aggregation techniques for creating a sales dashboard and supporting data-driven decision-making in a pizza business.
